## 컬러 시스템

> 기준 이미지: `ref_3d_diagonal.png`

| 토큰 | 역할 | HEX | RGB | OpenGL `glColor3f` |
|------|------|-----|-----|--------------------|
| `COLOR_BODY_DARK` | 머리·등·날개 (짙은 파랑) | `#006FCD` | 0, 111, 205 | `0.00, 0.44, 0.80` |
| `COLOR_BODY_LIGHT` | 몸통 앞면·뺨 (하늘색) | `#88C8E3` | 136, 200, 227 | `0.533, 0.784, 0.890` |
| `COLOR_CREST` | 정수리 돌기 (연한 하늘) | `#A0E3F7` | 160, 227, 247 | `0.63, 0.89, 0.97` |
| `COLOR_BEAK` | 부리·발 (노란색) | `#E7BA54` | 231, 186, 84 | `0.91, 0.73, 0.33` |
| `COLOR_BELLY` | 배 흰 점·눈 흰자 (흰색) | `#FBFCFB` | 251, 252, 251 | `0.98, 0.99, 0.98` |
| `COLOR_EYE` | 눈동자 (검정) | `#0C0D0C` | 12, 13, 12 | `0.05, 0.05, 0.05` |

### 사용 원칙
- 조명(`GL_LIGHTING`) 적용 시 위 값은 **ambient/diffuse material** 기준색으로 사용
- specular는 흰색(`1.0, 1.0, 1.0`)으로 고정, shininess는 부위별로 조정
  - 머리·등: `shininess 60` (광택 있음)
  - 몸통 앞: `shininess 30` (부드러움)
  - 부리·발: `shininess 20` (무광에 가까움)

## 모델링 참고 포인트

- **머리** : 몸통보다 큰 구 형태, 정수리에 하늘색 돌기 3개
- **몸통** : 납작한 타원형, 앞면 하늘색 + 흰 점 2개
- **부리** : 짧고 노란 삼각형 형태
- **눈** : 크고 동그란 검정 눈, 흰 하이라이트
- **날개/팔** : 작은 삼각형 날개
- **발** : 노란색, 짧고 통통함
