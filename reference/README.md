## 모델링 참고 포인트

- **머리** : 몸통보다 큰 구 형태, 정수리에 하늘색 돌기 3개
- **몸통** : 납작한 타원형, 앞면 하늘색 + 흰 점 2개
- **부리** : 짧고 노란 삼각형 형태
- **눈** : 크고 동그란 검정 눈, 흰 하이라이트
- **날개/팔** : 작은 삼각형 날개
- **발** : 노란색, 짧고 통통함
- **색상** : 짙은 파랑(머리·등) / 하늘색(몸통 앞) / 노란색(부리·발) / 흰색(배 점)
